# Korsi showcase → Nabz Enterprise feature inventory

Source: [interactive public Korsi showcase](https://korsi.ai/fa#explore-korsi), inspected 2026-10-26. The embedded organization is explicitly fictional. It proves UI behavior, not authenticated Korsi persistence, security, model choice, or pricing architecture. The separate Korsi subscription gate did not grant an authenticated dashboard session. The Nabz owner also specifically requests a **سند ریسک** workflow.

| Area | Observed in clickable showcase | Nabz CRM-v2 baseline | Issue #1 implementation / remaining gate |
| --- | --- | --- | --- |
| Manager desk | Personal/organization toggle; overdue, today, meetings, pending decisions; attention queue, calendar, owned cases and next actions | Existing CRM and team schedule | Executive desk with tenant records and attention counts. Combined calendar and personal/org switch still need verified access semantics. |

The priority is real tenant-scoped operations, typed evidence, review gates, and recoverable execution. Synthetic samples and local model claims must stay labeled until exercised against the target deployment.
